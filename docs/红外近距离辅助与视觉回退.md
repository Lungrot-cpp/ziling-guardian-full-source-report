# 红外近距离辅助与视觉回退

常规场景采用纯视觉；近距离、机位固定且热观测有效时可启用红外辅助筛选人物照片。远距离人体覆盖的热像元更少，热对比受背景、衣物与遮挡影响，不能假定红外在各距离都有同样效果。网页可关闭辅助；开启后，未配准、数据无效、超出标定区域或热像元不足均回退视觉。有效冷目标可以不显示普通绿框，但RGB跟踪与黄色/红色风险独立保留。

本包没有虚构标定值，默认标定头仍为false。需要在实际近距离使用工况下，同步采集RGB与热像，用至少4个非共线对应点填写JSON：pairs每行为[rgb_x,rgb_y,ir_x,ir_y]，均归一化到0..1；rgb_region为实测适用RGB矩形[x0,y0,x1,y1]。应覆盖目标活动范围，不使用测试中的合成点作为实测值。

先执行python board/tools/calibrate_fusion.py 实测点.json检查拟合；通过后追加--output board/recognition/software/src/fusion_calibration.h生成头文件，再重新编译。最大拟合残差须不超过1个热像元；这仅检查拟合一致性，不能替代独立真人/照片/远距离实测。机位或工作距离改变后重新标定或关闭辅助；地面四点标定与RGB/IR配准是两种不同标定。

系统没有测距器，也没有实现以米为单位的自动远近判断。回退依据热数据质量与标定适用域；远距离监测应使用视觉路径。
