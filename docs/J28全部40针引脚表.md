# J28全部40针与外设接线表

适用：Ti60F225 V4主板J7连接资料配套QSE转排针板，使用V12_FPS_Voice_J28_20261031工程。J28与主板J7同号直通。先断电，按实物1脚标记数针；不能按照片左右或线颜色判断。

## 电源与共地

- J28没有单独引出1.8V电源。语音转换器低压侧可从主板J8-2 VCC1V8取电，先确认针位并测量；不改J8原UART信号。
- 外部电源GND、语音G、舵机GND、灯板/灯带GND、转换器GND和主板GND必须连通。可用公共地接线端子分配，不将多根裸线硬塞入一个排针孔。
- 外部+5V只给外设供电，不与J28-3的板载+5V并联，不接任何信号脚。
- 转换器型号未知，不能按任意LV/HV板猜接线；必须支持1.8V与模块实际逻辑电平、推挽UART及两路相反方向。
- 对照主板和转接板原理图、当前编译pinout及RTL完成核对。实物针位、实际电压、外设供电能力、声音和长期运行尚未上板验证。
