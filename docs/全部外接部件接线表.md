# 全部外接部件接线表（当前J28工程）

适用工程：D:/fpga/V12_FPS_Voice_J28_20261031。
FPGA GPIO/球位/电压以该工程peri.xml及编译pinout为准；扩展针号按用户提供的260920说明书第26～27页和配套QSE转排针板对应。代码不会定义外设的供电针号。

注意：说明书与另一份原理图有冲突。当前代码voice_tx=B1、voice_busy=C2，按说明书对应J28-20/22，但语音实物针位未测。用户原SHT30 SDA接38脚，保持原接法，不按旧说明改36脚。

所有传感器SCL/SDA必须兼容3.3V，上拉不能是5V。灯板若要求5V数据高电平，J28-39至DIN需电平转换；舵机也需兼容3.3V控制电平，否则其信号需转换。LCD_POWER当前是灯板数据，不是灯板供电。

语音BUSY的FPGA侧（按说明书对应J28-22）到公共地加约10kΩ下拉。仅在确认实物针位后连接，不能用模块高压信号试错。

## 语音电平转换器

具体型号尚未提供，以下是功能接法，不代表某块转换板的物理脚序或丝印。应支持1.8V与模块实际逻辑电平、推挽UART，且两通道方向相反。

| 转换器功能端 | 接法 |
| --- | --- |
| FPGA侧电源/参考端 | 稳定1.8V；不接J28-1的3.3V或J28-3的5V |
| 模块侧电源/参考端 | 按SYN6288实物数字接口电平；只有确认5V逻辑后才接5V |
| GND | 公共地 |
| 通道1低压侧 | J28-20/B1，输入转换器 |
| 通道1模块侧 | SYN6288 RXD，转换器输出 |
| 通道2模块侧 | SYN6288 BY/BUSY，输入转换器 |
| 通道2低压侧 | J28-22/C2，转换器输出1.8V |
| OE/DIR等（若有） | 按具体转换器型号确定，不能从其他转换板接法推断 |

J28没有1.8V电源。此前另一份主板原理图标注J8-2为VCC1V8，可作为取电候选，但本次资料存在版本冲突，使用前必须核对实物并实测1.8V；它不是本次260920说明书对J28的映射结论。没有确认前，不盲接J8。转换板低压电源只是供电参考，不能用GPIO信号替代。

## 供电关系

- 主板继续使用原配电源。
- SHT30用板上3.3V；原支持5V输入的MLX90640模块沿用板上5V。
- 语音、灯板、灯带、现有5V舵机使用外部稳定5V，按负载选择足够供电能力，不从GPIO取电。
- 外部电源GND、J28-5/6、所有模块GND和转换器GND连通，可用公共接线端子分配。
- 外部+5V不与J28-3板载+5V并联。信号脚20/22/32/34/37/38/39/40均不是外设供电脚。

摄像头、HDMI显示器、网线、电脑下载/日志USB保持原配连接，不拆线改接J28。原电脑UART仍为system_uart_0_io_txd/GPIOR_28/R14和system_uart_0_io_rxd/GPIOL_02/R4，均3.3V；不接到语音模块。原V12按钮、蜂鸣器未指定实物接线，本次不新增针位。

本表覆盖已确认的外接部件端子；传感器若有额外ADDR/ALERT等端子或转换器有OE/DIR，需按具体实物版本确定，不虚构脚号。代码与编译报告已核对；未下载硬件、未测电压、未确认语音实物20/22连通或出声。
